An **UNOFFICIAL** Year Zero Engine adaptation set in the world of the S.T.A.L.K.E.R series. 

Includes: 
An interactive map of the zone [First 3 games combined] with tools to help you map your journey. A sync function to add/edit map icons between party members and the DM. 
A dossier to serve as your character sheet including the option to upload your own profile picture or pick from portraits that you may find familiar.
The entire 'S.T.A.L.K.E.R' adaptation rulebook. 

Stored locally, but can be exported as a save-file or code to be shared or saved for a later date.

https://panzerlamb.github.io/STALKER-TTRPG-PDA/

Currently, this is entirely a hobby project to be used when playing the included adaptation with friends :)
